# 会议纪要：本体论多智能体数据协作系统（Demo1）

- **日期**：2026年2月18日
- **参与者**：Vincent、AI 助手
- **主题**：基于本体论的多智能体数据协作系统设计与实现

---

## 一、会议目标

构建一套基于本体论的多智能体协作系统 Demo，能够：

- 用户通过自然语言提问
- 系统通过12个智能体协作完成从意图理解到数据查询、计算、回答、图表生成的全流程
- 支持多数据源（A大学/B大学），通过本体统一语义映射不同命名规范的数据

---

## 二、方案设计与讨论

### 2.1 整体架构

确定了12个智能体的流水线架构：

| 序号 | 智能体 | 职责 |
| --- | --- | --- |
| 1 | 意图澄清 | LLM 解析自然语言→结构化意图 |
| 2 | 知识验证 | 校验实体/属性是否在本体中存在 |
| 3 | 调度 | 分析复杂度，决定执行路径 |
| 4 | 查询规划 (A) | 构建对象子图 |
| 5 | 条件筛选 (B) | 结构化过滤条件 |
| 6 | 字段提取 (B) | 确定输出字段及类型 |
| 7 | 计算方法 (C) | 确定聚合规则 |
| 8 | DSL 查询 | 生成 SPARQL + SQL 中间产物 |
| 9 | 计算执行 | 在数据存储上执行实际查询 |
| 10 | 质检验证 | 检查结果完整性 |
| 11 | 答案回复 | LLM 生成自然语言回答 |
| 12 | 图表报告 | 生成可视化柱状图等 |

### 2.2 数据设计

- **本体**：学生管理系统领域本体，包含 Student、Teacher、Course、Score、Class 五个实体及其关系
- **A大学**：中文拼音缩写命名（表 `xuesheng`，字段 `xm`、`xb` 等）
- **B大学**：英文命名（表 `stu_info`，字段 `name`、`gender` 等）
- 通过映射配置实现本体字段到真实库表字段的转换

### 2.3 技术栈

- Python + Pandas（临时数据存储用 Excel 模拟）
- 千问大模型（通过硅基流动 API 调用）
- Matplotlib（图表生成）
- 预留 MySQL + Neo4j 数据库接口

## 三、实施过程

### 3.1 代码实现

完成了以下模块的开发：

- 本体定义 JSON + 本体管理器
- A/B 大学映射配置 + 映射管理器
- 数据存储抽象层（Sheet 实现）
- 千问 LLM 客户端（含 Mock 模式）
- 12 个智能体
- 流水线编排器
- CLI 命令入口（支持 query / interactive / ontology / mapping）
- 样例数据生成脚本

### 3.2 遇到的问题与解决

| 问题 | 原因 | 解决方案 |
| --- | --- | --- |
| API Key 401 认证失败 | 最初配置了 DashScope 地址，但 Key 是硅基流动的 | 修改 base_url 为 `api.siliconflow.cn/v1` |
| 模型不存在（400） | 硅基流动不支持 `Qwen2.5-Max` 模型名 | 改用 `Qwen/Qwen2.5-72B-Instruct` |
| LLM 返回 count 字段被验证拒绝 | `count` 是聚合计算结果，不是实体属性 | 知识验证智能体跳过聚合字段的校验 |
| 验证不通过导致流程中止 | 调度器对验证失败执行硬拒绝 | 改为警告并继续执行 |
| group_by 字符串 vs 列表 | LLM 返回字符串 `"gender"` 而非列表 `["gender"]` | 计算方法智能体自动归一化 |
| f-string 转义引号语法错误 | 嵌套引号导致语法错误 | 重写为字符串拼接方式 |

### 3.3 添加 Mock 模式

为应对 API 不可用的情况，在 LLM 客户端中添加了基于规则引擎的 Mock 模式：

- CLI 通过 `--mock` 参数控制
- Mock 模式使用关键词匹配本地解析意图，不调用外部 API
- 可用于演示和离线测试

## 四、测试验证结果

### 测试用例："统计A大学男生和女生的人数"

- **LLM 生成答案**：「A大学的男生和女生人数相同，都是5人。」
- **计算结果**：女=5，男=5 ✅
- **DSL (SQL)**：`SELECT t0.xb, COUNT(*) AS count_value FROM xuesheng t0 GROUP BY t0.xb` — 正确映射 A大学字段 ✅
- **DSL (SPARQL)**：完整生成 ✅
- **图表**：chart.png 柱状图已生成 ✅
- **中间产物**：intermediates.json 包含全12步输出 ✅
